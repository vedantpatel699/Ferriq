1. Purpose and scope

Forecasts when any radiant tube skin thermocouple in a fired heater pass will reach 475 °C, the polythionic stress corrosion cracking limit per API 530. The model is trained on historical operating data and exposed as an XGBoost ensemble distilled to JSON for in-browser inference.

2. Equipment context

Three furnaces in scope:

  • Heater 1 - 4-pass atmospheric residue heater feeding the vacuum unit. 4 radiant skin thermocouples per pass (Pass 3 has 3). Daily aggregated readings.
  • Heater 2 - 4-pass vacuum tower heater. 3 radiant skin thermocouples per pass. 4-hour cadence.
  • Heater 3 - Atmospheric heater for the first distillation column. Limited instrumentation (1 convection skin, 2 radiant skins). 4-hour cadence. Lower model fidelity expected.

3. Operating envelope

Skin TI range observed in training data: 250 to 510 °C. Below 250 °C is treated as a sensor-failure reading and excluded. Above 600 °C is also masked as sensor noise. Pass flows typical 80 to 130 m³/h per pass on Heater 1; 30 to 50 m³/h on Heater 2. Radiant box temperatures 600 to 720 °C.

5. Calculations

Target variable

For each pass: skin_max[t] = max(rad_skin_p{N}_a, ..., rad_skin_p{N}_d) at time t. The model predicts skin_max[t + 24h].

Hours-to-475 forecast

The trained 24-hour-ahead predictor is rolled forward in 24-hour steps for 7 days. The dashboard linearly interpolates the resulting trajectory to find the time at which it crosses 475 °C. If no crossing is found within 7 days, the slope between current and day-7 prediction is extrapolated.

Confidence band

Each thermocouple has THREE trained XGBoost models per TC: P10 (10th percentile), P50 (median, central forecast), and P90 (90th percentile). Trained with objective='reg:quantileerror' and quantile_alpha = 0.1 / 0.5 / 0.9. The chart band shown between P10 and P90 is the data-driven 80% prediction interval. All three models walk forward recursively and the band evolves naturally as the forecast horizon extends.

The forecast tile headline checks both the central P50 trajectory AND the upper P90 band. If P50 doesn't cross 475 but P90 does within the 7-year internal horizon, the tile reports 'Possible in N days (upper bound)'. Empirical coverage of the P10-P90 band on hold-out data ranges from ~50 to ~95% across TCs (target 80%) - reported in the About tab.

7. Pressure convention

Flows displayed as volumetric m³/h at metered conditions. Pressures shown in kPa (gauge or absolute as labelled). All temperatures in °C.

8. Series conventions on charts

The history chart now shows ONE pass at a time, with each individual radiant skin thermocouple on that pass drawn as its own line. Use the 'show pass' pill bar in the chart head to switch which pass is displayed. Solid lines = historical readings per TC. Dashed lines = per-TC P50 forecast (central). Filled bands = per-TC P10-P90 quantile-regression prediction interval (data-driven, 80% nominal coverage). Dashed red horizontal = 475 °C alarm. Dashed amber = 460 °C advisory. The four pass-level summary tiles at the top of the page remain unaffected by the chart selection - they always reflect every pass.

9. Time range behaviour

The topbar has TWO independent time controls. The PAST group (7D / 30D / 90D + custom 'd back' input) drives the history x-axis backward from the latest dataset timestamp; default is 30D. The FORECAST group (+7D / +90D / +1Y + custom 'd fwd' input) drives how far forward the chart shows the prediction trajectory; default is +7D. The forecast tile values (hours-to-475, 'Not expected within 7 years' verbiage, etc.) are computed once over a fixed 7-year internal horizon and do NOT change with the FORECAST pill. The pill only changes what slice of that trajectory the chart displays. For long horizons the chart x-axis is downsampled (weekly above 90D, biweekly above 1Y) to stay readable.

10. Data quality and limitations

Skin thermocouples below 150 °C or above 700 °C are masked as sensor faults. Pass 4 of Heater 2 has wider P10-P90 bands than other passes due to TC dropouts in the source data; treat its forecasts with extra skepticism. Heater 3 has only 3 thermocouples total across the heater, so per-pass forecasting is limited to one combined pass.

11. Common fault modes

  • Coke fouling - the dominant cause of skin TI drift upward. Builds slowly over months between decoke cycles.
  • Pass flow maldistribution - one pass takes more feed than its share, runs hotter to compensate. Shows up as one pass diverging from the others.
  • Burner imbalance / flame impingement - localized hot spot on one or two thermocouples; max-skin signal moves before pass-average.
  • Tube creep - sustained operation above 475 °C accelerates creep. The 475 °C limit is set conservatively to avoid this.
  • TC sensor drift / failure - flatlining or implausible jumps. The 150-700 °C mask filters these.

13. Model and training

The predictor uses a hybrid forecast composition: a linear regression on the last 30 days of skin-TI history (slope in °C/day) provides the central trajectory at every forecast horizon, and three XGBoost quantile models per TC (P10, P50, P90) provide the data-driven uncertainty band. Linear extrapolation correctly extends fouling trends beyond the training-data range; the quantile band captures normal day-to-day variation around the trend. At each forecast step, the band width = P90-P50 (upper) and P50-P10 (lower) from the XGBoost quantile spread, decorating the linear central. Per-TC modelling lets the dashboard monitor every thermocouple individually. Training uses chronological 80/20 split: first 80 percent of dates train, most recent 20 percent are held-out test, which tests whether the band widths reflect real out-of-sample variation.

Turnaround and upset rows are detected and excluded from training. A turnaround row is one where the maximum skin TI across all TCs in the furnace falls below 250 °C (cold furnace), dilated by 3 days each side to capture cool-down approach and warm-up startup transients. An upset row is one where the day-over-day change in max skin TI exceeds 50 °C (sensor glitch or large process disturbance). Across the three furnaces, 6 to 13 percent of rows are excluded as turnaround/upset; the remaining stable-operation data trains a model that is not biased by shutdown trajectories.

Decoke detection: each turnaround group is compared against the 7 days before and after. If post-restart skin TI is at least 30 °C lower than pre-shutdown, the turnaround is classified as a decoke (tube cleaning happened, fouling clock resets) and a new run begins. Otherwise the shutdown is treated as a maintenance stop and the previous run continues. The engineered feature days_since_run_start counts only operating time within the current run, so different runs align at t=0 instead of being averaged together. This is critical for fouling-rate prediction: the model now sees N independent fouling curves instead of one smeared curve over 5 years. The dashboard about-tab shows decoke dates and current days-into-run per furnace.

Hyperparameters: max_depth = 3, n_estimators = 80, learning_rate = 0.06, subsample = 0.85, colsample_bytree = 0.85. Three quantile models per TC (P10, P50, P90) using objective='reg:quantileerror'. Trees are dumped to a compact JSON node format and evaluated by a pure-JavaScript walker in this dashboard.

Feature set per pass: pass flow, IP steam injection, convection skin TI, crossover T, pass outlet T, calculated pass duty (where available), whole-furnace radiant box T, fuel gas flow, combustion air, plus engineered features for current-skin-max, 7-day rolling mean, skin-velocity (degC/day), cumulative duty integral, and days-since-data-start (proxy for cumulative coke deposition).

Retraining cadence: as new operating data accumulates, re-run train.py against the updated Excel. The dashboard will pick up the new model.json bundle on next load.
